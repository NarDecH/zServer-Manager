# คู่มือติดตั้ง zServer Manager

## ส่วนที่ 1: ติดตั้งโปรแกรม zServer Manager

### วิธีที่ 1 — ผ่าน Setup.exe (แนะนำ)

รัน `installer\Output\zServer-Setup-1.1.0.exe`:

1. กด UAC "ใช่" (ตัวติดตั้งต้องการสิทธิ์ admin)
2. โฟลเดอร์ปลายทางค่าเริ่มต้น `C:\zServer` (เปลี่ยนได้ในหน้า wizard — แต่เอกสารทั้งชุดอ้างอิง `C:\zServer`)
3. เลือกสร้าง shortcut บน desktop (ถ้าต้องการ) → ติดตั้ง → เปิดโปรแกรมทันที
4. ถอนติดตั้ง: Control Panel → Programs → "zServer Manager" — **ถอนเฉพาะไฟล์โปรแกรม** (เซอร์วิสและข้อมูลใน `www\`, `data\` ไม่ถูกลบ — ถอนเซอร์วิสผ่านโปรแกรม: ตั้งค่า → เซอร์วิส)

### วิธีที่ 2 — ใช้ไฟล์ exe โดยตรง

### ความต้องการของระบบ

- Windows 10 / 11 (64-bit)
- สิทธิ์ผู้ดูแลระบบ (Administrator) — จำเป็นเพราะโปรแกรมควบคุม Windows Service
- พื้นที่ว่างประมาณ 1 GB (โปรแกรม ~50 MB + Apache ~100 MB + PHP ~150 MB + MariaDB ~350 MB หลังแตกไฟล์)
- อินเทอร์เน็ต (ตอนติดตั้งคอมโพเนนต์ครั้งแรกเท่านั้น)

> หมายเหตุ: ไฟล์ `ZServerManager.exe` เป็นแบบ **self-contained** — ไม่ต้องติดตั้ง .NET runtime เพิ่ม

### ขั้นตอน

1. วางโฟลเดอร์ `zServer` ไว้ที่ `C:\zServer` (ต้องใช้ path นี้ เพราะ config ทั้งหมดอ้างอิงจากที่นี่)
2. ดับเบิลคลิก `C:\zServer\bin\ZServerManager.exe`
3. Windows จะถาม UAC "ต้องการอนุญาตให้แอปนี้ทำการเปลี่ยนแปลง...?" → กด **ใช่**
   (ถ้าไม่กด "ใช่" โปรแกรมจะเปิดไม่ได้ เพราะต้องใช้สิทธิ์ admin ในการควบคุมเซอร์วิส)

เคล็ดลับ: ถ้าไม่อยากกด UAC ทุกครั้ง สร้าง shortcut ผ่าน Task Scheduler แบบ "Run with highest privileges" แล้วให้เปิดผ่าน shortcut นั้นแทน

## ส่วนที่ 2: ติดตั้งคอมโพเนนต์ (Apache / PHP / MariaDB)

เปิดโปรแกรมครั้งแรก ถ้ายังไม่ติดตั้งอะไรเลย จะมีกล่องถามว่าจะเข้าหน้าติดตั้งเลยไหม — กด "ใช่" หรือกดปุ่ม **"ติดตั้ง / จัดการคอมโพเนนต์"** ที่หน้าหลัก

### ลำดับที่แนะนำ: Apache → PHP → MariaDB

**ขั้นที่ 0 — VC++ Redistributable (แนะนำให้ทำก่อน)**

Apache และ PHP ที่แจกบน Windows สร้างด้วย Visual C++ จึงต้องมี VC++ Redistributable ติดตั้งอยู่ในเครื่อง หน้าติดตั้งจะตรวจให้อัตโนมัติ:

- ถ้าขึ้น ✓ สีเขียว = มีอยู่แล้ว ข้ามได้
- ถ้าขึ้น ⚠ สีส้ม = กดปุ่ม **"ดาวน์โหลดและติดตั้ง VC++ Redistributable"** (โปรแกรมจะดาวน์โหลดจาก aka.ms แล้วเรียกตัวติดตั้งของ Microsoft ให้เอง)

**ขั้นที่ 1 — Apache**

1. เลือกเวอร์ชันจาก dropdown (ตัวบนสุด = ล่าสุด เช่น `Apache 2.4.71`)
2. กด **ดาวน์โหลด + ติดตั้ง** — โปรแกรมจะ:
   - ดาวน์โหลด zip จาก apachelounge.com พร้อมตรวจ SHA256
   - แตกไฟล์ลง `C:\zServer\apache\`
   - เขียน `conf\httpd.conf` ให้ (Listen พอร์ตที่ตั้ง, DocumentRoot ชี้ `www\`, log ชี้ `logs\`)
   - ทดสอบ config ด้วย `httpd -t`
   - ติดตั้งเป็น Windows Service ชื่อ `ZServerApache` (ถ้ากดหมดเลือกไว้)
3. เมื่อเสร็จจะถาม "ต้องการเริ่มใช้งานเลยหรือไม่?" — กดใช่ได้เลย

**ขั้นที่ 2 — PHP**

1. เลือกเวอร์ชัน (แนะนำตัวล่าสุด เช่น `PHP 8.5.13`) — **โปรแกรมเลือกให้เฉพาะรุ่น Thread Safe** เพราะต้องใช้เป็นโมดูลของ Apache
2. กด **ดาวน์โหลด + ติดตั้ง** — โปรแกรมจะ:
   - ดาวน์โหลด/ตรวจ SHA256/แตกไฟล์ลง `C:\zServer\php\`
   - สร้าง `php.ini` จาก `php.ini-development` + แทรกค่าที่จัดการ (memory_limit, timezone Asia/Bangkok, extensions เช่น mysqli/mbstring/curl/gd)
   - **เขียน `httpd.conf` ใหม่โดยใส่ `LoadModule php_module` + `PHPIniDir` ให้อัตโนมัติ** — จบขั้นนี้ Apache รัน PHP ได้ทันที
3. ถ้า Apache กำลังรันอยู่ โปรแกรมจะหยุดชั่วคราวเพื่อเปลี่ยนไฟล์ แล้วเริ่มใหม่ได้จากหน้าหลัก

**ขั้นที่ 3 — MariaDB**

1. เลือกเวอร์ชัน (เช่น `MariaDB 11.4.10` สาย LTS หรือ `11.8.6` สายล่าสุด)
2. กด **ดาวน์โหลด + ติดตั้ง** — โปรแกรมจะ:
   - ดาวน์โหลด/ตรวจ/แตกไฟล์ลง `C:\zServer\mariadb\`
   - เขียน `my.ini` (พอร์ต, datadir ชี้ `data\`, utf8mb4)
   - รัน `mariadb-install-db` สร้างโฟลเดอร์ข้อมูล `C:\zServer\data\` (ครั้งแรกเท่านั้น)
   - ติดตั้งเป็น Windows Service ชื่อ `ZServerMariaDB`
3. หลังเริ่มใช้งาน แนะนำตั้งรหัสผ่าน root ผ่านหน้า **ตั้งค่า → MariaDB → ตั้งรหัสผ่าน root…** (ค่าเริ่มต้นรหัสผ่านว่าง)

### ทางเลือก: ติดตั้งผ่าน command line (สำหรับ scripting)

ถ้าต้องการติดตั้งอัตโนมัติ (เช่นเขียนสคริปต์ setup เครื่องใหม่) ใช้เครื่องมือ CLI ที่มากับโปรเจกต์ — ใช้โค้ดชุดเดียวกับ GUI:

```bat
:: เปิด cmd แบบ Run as administrator แล้ว:
cd C:\zServer\tools\ZServer.Installer\bin\Debug\net10.0-windows

:: ติดตั้งทั้ง 3 ตัว (เวอร์ชันแนะนำ) + เริ่มเซอร์วิส
ZServer.Installer.exe apache php mariadb --start

:: เลือกเฉพาะบางตัว / เวอร์ชันเฉพาะ
ZServer.Installer.exe php --version=8.4.28
ZServer.Installer.exe mariadb --no-service

:: ดูรายการเวอร์ชันทั้งหมดที่รองรับ
ZServer.Installer.exe
```

เวอร์ชันแนะนำของ CLI: Apache 2.4.71, PHP 8.5.13, MariaDB 11.4.10 (สาย LTS)

### ตรวจว่าติดตั้งสำเร็จ

- หน้าหลักการ์ด Apache/PHP/MariaDB ขึ้น **● กำลังทำงาน** พร้อมเวอร์ชันถูกต้อง
- เปิด [http://localhost](http://localhost) เจอหน้า "✅ zServer ทำงานแล้ว!" และ [http://localhost/phpinfo.php](http://localhost/phpinfo.php) แสดง phpinfo ได้

## ส่วนที่ 3: เปิดพอร์ตใน Windows Firewall

ค่าเริ่มต้น Apache ใช้พอร์ต 80 และ MariaDB ใช้ 3306 — ถ้าต้องการให้ **เครื่องอื่นในเครือข่าย** เข้าถึงได้ (ไม่ใช่แค่ localhost):

1. กดปุ่ม **"เปิดพอร์ต Firewall"** บนหน้าหลัก — โปรแกรมจะเพิ่ม rule อนุญาต TCP 80 และ 3306 ให้อัตโนมัติ
2. ถ้าเปลี่ยนพอร์ตแล้ว กดปุ่มนี้ซ้ำเพื่อเปิดพอร์ตใหม่ด้วย

> ความปลอดภัย: การเปิดพอร์ต MariaDB 3306 ให้เครือข่ายภายนอกมีความเสี่ยง หากไม่จำเป็น ให้เปิดเฉพาะพอร์ต 80

## ส่วนที่ 4: ทำงานร่วมกับ XAMPP เดิม

ถ้าเครื่องลง XAMPP ไว้ (เช่นที่ `C:\xampp`) มี 2 ทางเลือก:

**ทางเลือก A — ใช้ zServer บนพอร์ต 80/3306 และปิด XAMPP (แนะนำถ้าต้องการเปลี่ยนมาใช้ zServer)**

1. หยุดเซอร์วิสของ XAMPP: เปิด XAMPP Control Panel → กด Stop ทุกโมดูล หรือ
   ```
   sc stop Apache2.4
   sc stop mysql
   ```
   (ชื่อเซอร์วิสขึ้นกับการตั้งค่าเดิม) และตั้งให้ไม่ auto-start:
   ```
   sc config Apache2.4 start= demand
   sc config mysql start= demand
   ```
2. เปิด zServer Manager แล้วกด **เริ่ม** — โปรแกรมจะตรวจพอร์ตว่างก่อนเริ่มเสมอ

**ทางเลือก B — ใช้สองตัวพร้อมกัน คนละพอร์ต**

1. เปิด zServer Manager → **ตั้งค่า → Apache → พอร์ต** เปลี่ยนเป็น `8080`, **MariaDB → พอร์ต** เป็น `3307`
2. กด **บันทึกและใช้ค่าใหม่** (โปรแกรมเขียน config ให้ใหม่เอง) แล้วรีสตาร์ทเซอร์วิส
3. เว็บของ zServer จะอยู่ที่ http://localhost:8080

> โปรแกรมนี้ไม่ลบหรือแก้ไฟล์ของ XAMPP เด็ดขาด — ทุกอย่างใน `C:\zServer` แยกจาก XAMPP สนิท

## ส่วนที่ 5: ถอนการติดตั้ง (Uninstall)

1. เปิดโปรแกรม → หยุดเซอร์วิสทั้งหมด → ปิดโปรแกรม
2. ถอนเซอร์วิส: `ตั้งค่า → เซอร์วิส → ถอนเซอร์วิส Apache / ถอนเซอร์วิส MariaDB`
   (หรือใช้ command line: `sc delete ZServerApache`, `sc delete ZServerMariaDB`)
3. ลบโฟลเดอร์ `C:\zServer` ทิ้งได้ทั้งโฟลเดอร์

> ก่อนลบ: สำรองข้อมูลสำคัญจาก `www\` และ `data\` (หรือใช้ mariadb-dump) ก่อนเสมอ
