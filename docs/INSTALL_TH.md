# คู่มือติดตั้ง zServer Manager

เอกสารนี้ครอบคลุมทุกวิธีติดตั้ง + ทุกขั้นตอนหลังติดตั้ง แบบละเอียด

---

## ส่วนที่ 1: ติดตั้งโปรแกรม zServer Manager (เลือก 1 ใน 3 วิธี)

### ความต้องการของระบบ

- Windows 10 / 11 (64-bit)
- สิทธิ์ผู้ดูแลระบบ (Administrator) — จำเป็นเพราะโปรแกรมควบคุม Windows Service
- พื้นที่ว่าง ~1 GB (โปรแกรม ~50 MB + Apache ~100 MB + PHP ~150 MB + MariaDB ~350 MB หลังแตกไฟล์)
- อินเทอร์เน็ต (ตอนติดตั้งคอมโพเนนต์ครั้งแรกเท่านั้น)

> หมายเหตุ: ไฟล์ `ZServerManager.exe` เป็นแบบ **self-contained** — ไม่ต้องติดตั้ง .NET runtime เพิ่ม

### วิธีที่ 1 — ผ่าน Setup.exe (แนะนำ)

รัน `installer\Output\zServer-Setup-1.5.0.exe` (โหลดได้จาก [หน้า Releases](https://github.com/NarDecH/zServer-Manager/releases)):

1. กด UAC "ใช่" (ตัวติดตั้งต้องการสิทธิ์ admin)
2. หน้า wizard: โฟลเดอร์ปลายทางค่าเริ่มต้น `C:\zServer` (เปลี่ยนได้ — แต่เอกสารทั้งชุดอ้างอิง `C:\zServer`)
3. เลือกสร้าง shortcut บน Desktop (ถ้าต้องการ) → **ติดตั้ง**
4. เมื่อจบจะมีปุ่ม "เปิด zServer Manager ตอนนี้เลย" — กดได้เลย (โปรแกรมรันแบบ admin โดยไม่เด้ง UAC ซ้ำ เพราะตัวติดตั้งรันแบบ admin อยู่แล้ว)
5. สิ่งที่ Setup ติดตั้งให้: `bin\ZServerManager.exe` + โฟลเดอร์ `docs\` (คู่มือ offline) + shortcut เมนูเริ่ม/Desktop — **ไม่แตะโฟลเดอร์อื่นของ zServer ถ้ามีของเดิมอยู่**

**การถอนติดตั้ง:** Control Panel → Programs → "zServer Manager" → ถอน (ถอนเฉพาะไฟล์โปรแกรม — เซอร์วิสและข้อมูลใน `www\`, `data\` ไม่ถูกลบ ถอนเซอร์วิสผ่านโปรแกรม: ตั้งค่า → เซอร์วิส)

### วิธีที่ 2 — ใช้ไฟล์ exe โดยตรง (portable)

1. วางโฟลเดอร์ `zServer` ไว้ที่ `C:\zServer`
2. ดับเบิลคลิก `C:\zServer\bin\ZServerManager.exe` → กด UAC "ใช่"
3. เสร็จ (โปรแกรมหาโฟลเดอร์หลักอัตโนมัติจากตำแหน่งไฟล์ตัวเอง หรือตั้งผ่าน env `ZSERVER_HOME`)

เคล็ดลับ: ถ้าไม่อยากกด UAC ทุกครั้ง ใช้ **ตั้งค่า → ทั่วไป → "เปิดโปรแกรมอัตโนมัติเมื่อเข้าสู่ระบบ Windows"** (สร้าง Task Scheduler ให้ — ได้สิทธิ์ admin โดยไม่เด้ง UAC เวลาเปิดเครื่อง)

### วิธีที่ 3 — ผ่าน command line (สำหรับ scripting)

```bat
:: เปิด cmd แบบ Run as administrator แล้ว:
cd C:\zServer\tools\ZServer.Installer\bin\Debug\net10.0-windows

:: ดูรายการเวอร์ชันที่รองรับ (ดึงเวอร์ชันใหม่จากเว็บให้ด้วยถ้าออนไลน์)
ZServer.Installer.exe

:: ติดตั้งทั้ง 3 ตัว (เวอร์ชันแนะนำ) + เริ่มเซอร์วิส
ZServer.Installer.exe apache php mariadb --start

:: เลือกเฉพาะบางตัว / เวอร์ชันเฉพาะ / ไม่ติดตั้งเซอร์วิส
ZServer.Installer.exe php --version=8.6.0
ZServer.Installer.exe mariadb --no-service
```

เวอร์ชันแนะนำของ CLI: Apache ล่าสุด, PHP ล่าสุด, MariaDB สาย LTS (11.4)

### หลังเปิดโปรแกรมครั้งแรก

โปรแกรมจะ:
1. สร้างโครงสร้างโฟลเดอร์ที่จำเป็น (`www\`, `logs\`, `downloads\`, `backups\`) และไฟล์ `zserver.json`
2. ตรวจเวอร์ชันใหม่จากเว็บทางการ (เบื้องหลัง)
3. ถ้ายังไม่ติดตั้งคอมโพเนนต์เลย → ถามว่าจะเปิดหน้า "ติดตั้ง" เลยไหม

## ส่วนที่ 2: ติดตั้งคอมโพเนนต์ (Apache / PHP / MariaDB)

เปิดหน้า **"ติดตั้ง / จัดการคอมโพเนนต์"** จะเห็น 5 แถว: VC++ Redistributable, Apache, PHP, MariaDB, Adminer

### ลำดับที่แนะนำ: VC++ Redistributable → Apache → PHP → MariaDB → Adminer

**ขั้นที่ 0 — VC++ Redistributable (ทำก่อนเสมอ)**

Apache และ PHP ที่แจกบน Windows สร้างด้วย Visual C++ จึงต้องมี VC++ Redistributable ในเครื่อง:

- ถ้าแถวบนสุดขึ้น ✓ สีเขียว = มีอยู่แล้ว ข้ามได้
- ถ้าขึ้น ⚠ สีส้ม = กด **"ดาวน์โหลดและติดตั้ง VC++ Redistributable"** (โปรแกรมโหลดจาก aka.ms แล้วเรียกตัวติดตั้งของ Microsoft ให้) — หลังติดตั้งแนะนำรีสตาร์ทเครื่องหนึ่งครั้ง

**ขั้นที่ 1 — Apache**

1. เลือกเวอร์ชันจาก dropdown (ตัวบนสุด = ล่าสุด เช่น `Apache 2.4.71`)
2. กด **ดาวน์โหลด + ติดตั้ง** — โปรแกรมจะ:
   - ดาวน์โหลด zip จาก apachelounge.com พร้อมตรวจ SHA256
   - หยุดเซอร์วิสเดิม (ถ้ากำลังรัน) และสำรองโฟลเดอร์เก่าลง `backups\apache-old-<เวลา>\`
   - แตกไฟล์ลง `C:\zServer\apache\`
   - เขียน `conf\httpd.conf` ให้ (Listen พอร์ตที่ตั้ง, DocumentRoot ชี้ `www\`, log ชี้ `logs\`, เชื่อม PHP อัตโนมัติถ้าติดตั้งแล้ว)
   - ทดสอบ config ด้วย `httpd -t` — ไม่ผ่านจะรายงานและไม่ติดตั้งต่อ
   - ติดตั้งเป็น Windows Service `ZServerApache` (ถ้าติ๊ก "ติดตั้งเป็น Windows Service" ไว้)
3. เมื่อเสร็จจะถาม "ต้องการเริ่มใช้งานเลยหรือไม่?" — กดใช่ได้เลย

**ขั้นที่ 2 — PHP**

1. เลือกเวอร์ชัน (dropdown **ดึงรายการใหม่จาก php.net อัตโนมัติ** เช่น `PHP 8.6.0`) — โปรแกรมเลือกให้เฉพาะรุ่น **Thread Safe** เพราะต้องใช้เป็นโมดูลของ Apache
2. กด **ดาวน์โหลด + ติดตั้ง** — โปรแกรมจะ:
   - ดาวน์โหลด/ตรวจ SHA256 (จาก php.net โดยตรง)/แตกไฟล์
   - ติดตั้งเข้า **ระบบหลายเวอร์ชัน**: เก็บไว้ที่ `php-versions\8.5.13\` แล้วชี้ `php\` (junction) ไปที่เวอร์ชันนี้ — สลับเวอร์ชันภายหลังได้ในไม่กี่วินาทีโดยไม่ต้องโหลดซ้ำ
   - สร้าง `php.ini` จาก `php.ini-development` + แทรกค่าที่จัดการ (memory_limit, timezone Asia/Bangkok, extensions ที่เปิดไว้, OPcache, Xdebug ถ้าเปิด)
   - **เขียน `httpd.conf` ใหม่โดยใส่ `LoadModule php_module` + `PHPIniDir` ให้อัตโนมัติ**
3. ถ้า Apache กำลังรันอยู่ โปรแกรมจะหยุดชั่วคราวเพื่อเปลี่ยนไฟล์ → เริ่มใหม่จากหน้าหลักได้

**ขั้นที่ 3 — MariaDB**

1. เลือกเวอร์ชัน (เช่น `MariaDB 11.4.10` สาย LTS หรือ `11.8.6` สายล่าสุด)
2. กด **ดาวน์โหลด + ติดตั้ง** — โปรแกรมจะ:
   - ดาวน์โหลด/ตรวจ/แตกไฟล์ลง `C:\zServer\mariadb\`
   - เขียน `my.ini` (พอร์ต, datadir, **bind-address = 127.0.0.1** ปลอดภัยไว้ก่อน, utf8mb4)
   - รัน `mariadb-install-db` สร้างโฟลเดอร์ข้อมูล `C:\zServer\data\` (ครั้งแรกเท่านั้น)
   - ติดตั้งเป็น Windows Service `ZServerMariaDB`
3. **หลังติดตั้งโปรแกรมจะถามตั้งรหัสผ่าน root ทันที** (ค่าเริ่มต้นรหัสผ่านว่าง — ไม่ปลอดภัย) — แนะนำตั้งเลย โปรแกรมจะเข้ารหัสเก็บไว้ในเครื่อง (DPAPI) เพื่อให้งานสำรองอัตโนมัติใช้ได้

**ขั้นที่ 4 — Adminer (จัดการฐานข้อมูลผ่านเว็บ)**

1. กด **ดาวน์โหลด + ติดตั้ง** (ไฟล์เดียว ~500KB จาก adminer.org → `www\adminer.php`)
2. เปิดใช้ที่ [http://localhost/adminer.php](http://localhost/adminer.php) — กรอก user/password ที่สร้างไว้

### ตรวจว่าติดตั้งสำเร็จ

- หน้าหลักการ์ด Apache/PHP/MariaDB ขึ้น **● กำลังทำงาน** พร้อมเวอร์ชันถูกต้อง
- เปิด [http://localhost](http://localhost) เจอหน้า "✅ zServer ทำงานแล้ว!" และ [http://localhost/phpinfo.php](http://localhost/phpinfo.php) แสดง phpinfo ได้

### ติดตั้งผ่าน command line (สำหรับ scripting)

```bat
:: เปิด cmd แบบ Run as administrator แล้ว:
cd C:\zServer\tools\ZServer.Installer\bin\Debug\net10.0-windows

:: ติดตั้งทั้ง 3 ตัว (เวอร์ชันแนะนำ) + เริ่มเซอร์วิส
ZServer.Installer.exe apache php mariadb --start

:: เลือกเฉพาะบางตัว / เวอร์ชันเฉพาะ / ไม่ติดตั้งเซอร์วิส
ZServer.Installer.exe php --version=8.4.28
ZServer.Installer.exe mariadb --no-service
```

CLI ใช้โค้ดชุดเดียวกับ GUI และดึงรายการเวอร์ชันใหม่จากเว็บให้ด้วย

### เปลี่ยนเวอร์ชัน / อัพเดท PHP โดยไม่โหลดซ้ำ

- **สลับระหว่างเวอร์ชันที่เคยติดตั้งแล้ว**: ตั้งค่า → PHP → "เวอร์ชัน PHP ที่ใช้งาน" → เลือก → สลับเวอร์ชัน (โปรแกรมหยุด Apache → เปลี่ยน junction → เขียน php.ini → เริ่ม Apache ให้ ในไม่กี่วินาที)
- ติดตั้งเวอร์ชันใหม่ครั้งแรก: ใช้หน้า "ติดตั้ง" ตามปกติ (โปรแกรมเก็บเข้า `php-versions\` ให้เอง)

## ส่วนที่ 3: เปิดพอร์ตใน Windows Firewall

ค่าเริ่มต้น Apache ใช้พอร์ต 80 (HTTPS 443) และ MariaDB 3306 — ถ้าต้องการให้ **เครื่องอื่นในเครือข่าย** เข้าถึงได้:

1. กดปุ่ม **"เปิดพอร์ต Firewall"** บนหน้าหลัก — เพิ่ม rule อนุญาต TCP 80 และ 3306
2. หน้า **HTTPS** มีปุ่ม "เปิดพอร์ต 443 ใน Firewall" แยกไว้
3. ถ้าเปลี่ยนพอร์ตแล้ว กดปุ่มนี้ซ้ำเพื่อเปิดพอร์ตใหม่

> ความปลอดภัย: MariaDB มี `bind-address = 127.0.0.1` กันไว้เป็นค่าเริ่มต้น (เครื่องอื่นเชื่อมต่อไม่ได้แม้เปิดพอร์ต) — ปิดได้ในหน้าตั้งค่า (มีเตือน)

## ส่วนที่ 4: ทำงานร่วมกับ XAMPP เดิม

**ทางเลือก A — ใช้ zServer บนพอร์ต 80/3306 และปิด XAMPP**

1. หยุดเซอร์วิสของ XAMPP (XAMPP Control Panel → Stop หรือ `sc stop Apache2.4`)
2. ตั้งให้ไม่ auto-start: `sc config Apache2.4 start= demand`
3. เปิด zServer Manager → **เริ่ม** — ถ้าพอร์ตยังชน โปรแกรมจะแจ้งว่าใครใช้ + **ปุ่มเสนอพอร์ตว่างอัตโนมัติ** (กดเปลี่ยนแล้วติดตั้ง/เริ่มต่อได้เลย)

**ทางเลือก B — ใช้สองตัวพร้อมกัน คนละพอร์ต**

1. ตั้งค่า → Apache → พอร์ต `8080`, MariaDB → พอร์ต `3307` → บันทึก
2. เว็บ zServer อยู่ที่ http://localhost:8080

> โปรแกรมไม่ลบหรือแก้ไฟล์ของ XAMPP เด็ดขาด — ทุกอย่างใน `C:\zServer` แยกจาก XAMPP สนิท

## ส่วนที่ 5: ตั้งค่าเปิดโปรแกรมอัตโนมัติเมื่อเปิดเครื่อง

**ตั้งค่า → ทั่วไป**:

| ตัวเลือก | ผล |
|---|---|
| ☑ เปิดโปรแกรมอัตโนมัติเมื่อเข้าสู่ระบบ Windows | สร้าง Task Scheduler `ZServerManager` แบบ Run with highest privileges — เปิดเองตอน logon พร้อมสิทธิ์ admin โดยไม่เด้ง UAC (แอปต้องการ admin จึงใช้ Startup folder ไม่ได้) |
| ☑ เริ่มเซอร์วิส Apache + MariaDB ทันทีที่เปิดโปรแกรม | ใช้คู่กัน → เว็บพร้อมใช้หลัง logon ไม่กี่วินาที |
| ☑ ย่อ/ปิดหน้าต่างแล้วซ่อนไว้ใน tray | เปิดมาเป็นเงียบ ๆ ไม่รบกวน |

กด **บันทึกและใช้ค่าใหม่** = มีผลทันที (ตรวจสถานะ Task Scheduler จริงแล้ว sync ให้ด้วย)

## ส่วนที่ 6: ถอนการติดตั้ง (Uninstall)

1. เปิดโปรแกรม → หยุดเซอร์วิสทั้งหมด → ปิดโปรแกรม
2. ถอนเซอร์วิส: **ตั้งค่า → เซอร์วิส → ถอนเซอร์วิส Apache / ถอนเซอร์วิส MariaDB** (หรือ `sc delete ZServerApache`, `sc delete ZServerMariaDB`)
3. ถ้าติดตั้งผ่าน Setup.exe → ถอนผ่าน Control Panel (ถอนเฉพาะไฟล์โปรแกรม — ข้อมูลไม่หาย)
4. ลบโฟลเดอร์ `C:\zServer` ทิ้งได้ทั้งโฟลเดอร์

> ⚠ ก่อนลบ: สำรองข้อมูลสำคัญจาก `www\` และ `data\` (หรือใช้ mariadb-dump) ก่อนเสมอ
