# คู่มือการใช้งาน zServer Manager

เอกสารนี้อธิบายทุกหน้าจอและ workflow ที่ใช้บ่อยของโปรแกรม `bin\ZServerManager.exe`

---

## 1. หน้าต่างหลัก (แดชบอร์ด)

```
┌────────────────────────────────────────────────────────────────┐
│ ⚙ zServer Manager                                             │
│ โฟลเดอร์หลัก: C:\zServer | โหมดเซอร์วิส: Windows Service      │
├───────────────┬─────────────────┬─────────────────────────────┤
│ Apache        │ PHP             │ MariaDB                     │
│ ● กำลังทำงาน  │ ● กำลังทำงาน    │ ○ หยุดอยู่                  │
│ เวอร์ชัน 2.4… │ เวอร์ชัน 8.5.13 │ เวอร์ชัน 11.4.10 พอร์ต 3306 │
│ [เริ่ม][หยุด][รีสตาร์ท] │ [เปิด phpinfo] │ [เริ่ม][หยุด][รีสตาร์ท] │
├────────────────────────────────────────────────────────────────┤
│ [ติดตั้ง/จัดการคอมโพเนนต์][อัพเดท][ตั้งค่า][แก้ไขไฟล์ Config]   │
│ [ดู Logs][เริ่มทั้งหมด][หยุดทั้งหมด][เปิดพอร์ต Firewall]        │
│ [เปิดเว็บ localhost]                                            │
├────────────────────────────────────────────────────────────────┤
│ บันทึกเหตุการณ์ (สด) — แสดง log แบบเรียลไทม์                    │
├────────────────────────────────────────────────────────────────┤
│ Apache: กำลังทำงาน | MariaDB: หยุดอยู่ | PHP: กำลังทำงาน      │
└────────────────────────────────────────────────────────────────┘
```

### สัญลักษณ์สถานะ

| สัญลักษณ์ | ความหมาย |
|---|---|
| ● (เขียว) | กำลังทำงานปกติ |
| ○ (เทา) | หยุดอยู่ |
| ◌ (น้ำตาล) | ยังไม่ได้ติดตั้ง |
| ⚠ (ส้ม) | พอร์ตถูกโปรแกรมอื่นใช้ (มักเป็น XAMPP) |
| ✖ (แดง) | มีปัญหา — ดูรายละเอียดใต้สถานะ |

### ปุ่มควบคุม

- **เริ่ม / หยุด / รีสตาร์ท** — ควบคุม Apache และ MariaDB (PHP ไม่มีเซอร์วิสของตัวเอง — ทำงานผ่าน Apache)
  ก่อนเริ่มทุกครั้งโปรแกรมจะ **ตรวจพอร์ตก่อนเสมอ** ถ้าพอร์ตถูกใช้อยู่จะแจ้งว่าโปรแกรมใดใช้ (เช่น "พอร์ต 80 ถูกใช้โดย Apache น่าจะมาจาก XAMPP") พร้อมวิธีแก้
- **เริ่มทั้งหมด / หยุดทั้งหมด** — ควบคุมทีเดียวทั้งสองตัว (เริ่ม MariaDB ก่อน Apache / หยุด Apache ก่อน MariaDB)
- **เปิดพอร์ต Firewall** — เพิ่ม rule อนุญาตพอร์ต HTTP และ MariaDB ใน Windows Firewall
- **เปิดเว็บ localhost** — เปิด browser ไปที่ http://localhost:พอร์ตที่ตั้งไว้

### ย่อหน้าต่างไป tray

ปุ่มย่อหน้าต่าง (−) จะซ่อนโปรแกรมไปที่ไอคอน tray ข้างนาฬิกา (โปรแกรมและเซอร์วิสยังทำงานต่อ) กดไอคอนซ้ำหรือดับเบิลคลิกเพื่อเปิดกลับ เมนูคลิกขวาที่ไอคอน tray มี:

- แสดงหน้าต่างหลัก
- เริ่มทั้งหมด / หยุดทั้งหมด
- เปิดเว็บ localhost
- ออกจากโปรแกรม

เมื่อปิดหน้าต่างขณะเซอร์วิสกำลังรัน โปรแกรมจะถามว่าจะหยุดเซอร์วิสด้วยหรือปล่อยให้ทำงานต่อ

## 2. หน้า "ติดตั้ง / จัดการคอมโพเนนต์"

ใช้เมื่อ: ติดตั้งครั้งแรก / เปลี่ยนเวอร์ชัน / ติดตั้งซ้ำเพื่อซ่อมไฟล์

- **แถว VC++ Redistributable** — ตรวจให้ว่ามีตัวเสริมที่ Apache/PHP ต้องใช้ ถ้าไม่มีกดปุ่มด้านขวาเพื่อติดตั้งให้เลย
- **แต่ละคอมโพเนนต์** — ดูสถานะติดตั้งปัจจุบัน + เลือกเวอร์ชันจาก dropdown (เวอร์ชันที่ติดตั้งอยู่มีเครื่องหมาย ✓) + กด "ดาวน์โหลด + ติดตั้ง"
- **ตัวเลือก "ติดตั้งเป็น Windows Service"** — เปิดไว้ = ลงทะเบียนเซอร์วิสให้เริ่มเองตอนเปิดเครื่อง
- **ความคืบหน้า** — แสดงเปอร์เซ็นต์ + รายละเอียดทุกขั้น (ดาวน์โหลด → แตกไฟล์ → เตรียมโฟลเดอร์ → เขียน config → ติดตั้งเซอร์วิส)

ระหว่างติดตั้ง โปรแกรมจะ:
1. ตรวจ SHA256 ของไฟล์ที่โหลด (ป้องกันไฟล์เสียหาย)
2. หยุดเซอร์วิสเดิม (ถ้ากำลังรัน) และ **สำรองโฟลเดอร์เดิมลง `backups\`** ก่อนเขียนทับเสมอ
3. เขียน config ที่เกี่ยวข้องให้ใหม่อัตโนมัติ (เช่น ติดตั้ง PHP แล้ว httpd.conf จะได้ LoadModule php ให้เอง)
4. Apache: ทดสอบ `httpd -t` — ถ้า config ไม่ผ่านจะรายงานทันทีและไม่เข้าขั้นติดตั้งเซอร์วิส

## 3. หน้า "อัพเดท"

ใช้เมื่อ: ต้องการเวอร์ชันใหม่ของคอมโพเนนต์ที่ติดตั้งอยู่

1. กด **"ตรวจสอบเวอร์ชันล่าสุดจากเว็บทางการ"** — โปรแกรมสอบจาก
   - PHP: `releases.json` ของ windows.php.net
   - Apache: หน้า download ของ ApacheLounge
   - MariaDB: หน้า archive ของ mariadb.org
2. เทียบกับเวอร์ชันที่ติดตั้งอยู่ แล้วกดปุ่มอัพเดทของตัวที่ต้องการ
3. กระบวนการอัพเดทใช้ขั้นตอนเดียวกับการติดตั้ง (สำรองโฟลเดอร์เดิม → แทนที่ → คง config) — **ข้อมูลฐานข้อมูลใน `data\` ไม่ถูกลบ**
4. ถ้าเว็บล่ม/ตรวจไม่ได้ ใช้รายการเวอร์ชันที่โปรแกรมรู้จักไว้ (แคตตาล็อก) แทนได้จากหน้า "ติดตั้ง"

หมายเหตุสำหรับ MariaDB ข้ามสายใหญ่ (เช่น 10.11 → 11.x): หลังอัพเดทและเริ่มเซอร์วิส รันคำสั่ง
`mariadb\bin\mariadb-upgrade.exe --port=พอร์ต -u root -p` หนึ่งครั้งเพื่อปรับโครงสร้างระบบภายใน

การกลับคืน (rollback): ถ้าเวอร์ชันใหม่มีปัญหา — หยุดเซอร์วิส, ลบโฟลเดอร์ `apache\` (หรือ php\mariadb\), ย้ายโฟลเดอร์ใน `backups\<ชื่อ>-<เวลา>\` กลับมาแทน, เริ่มเซอร์วิสใหม่

## 4. หน้า "ตั้งค่า" — 5 แท็บ

ทุกครั้งที่กด **บันทึกและใช้ค่าใหม่**: โปรแกรมจะบันทึก `zserver.json`, เขียน config ที่เกี่ยวข้องใหม่ (สำรองเดิมก่อนเขียนทับทุกครั้งลง `backups\configs\`), และถามรีสตาร์ทเซอร์วิสถ้ากำลังรันอยู่

### แท็บ ทั่วไป

| ค่า | ความหมาย |
|---|---|
| เปิดโปรแกรมอัตโนมัติเมื่อเข้าสู่ระบบ Windows | สร้าง Task Scheduler (`ZServerManager`) แบบ Run with highest privileges — เปิดเองตอน logon พร้อมสิทธิ์ admin โดยไม่เด้ง UAC (เพราะแอปต้องการ admin จึงใช้วิธีนี้แทน Startup folder) |
| เริ่มเซอร์วิส Apache + MariaDB ทันทีที่เปิดโปรแกรม | ใช้คู่กับข้างบน = เว็บพร้อมใช้หลัง logon ไม่กี่วินาที (ตรวจพอร์ตก่อนเริ่มเสมอ) |
| ย่อ/ปิดหน้าต่างแล้วซ่อนไว้ใน tray | ปิดโปรแกรมไม่ต้องถาม เก็บไว้ใน tray |
| ใช้ธีมมืด | ธีมมืด (ค่าเริ่มต้น) / สว่าง — สลับได้เร็วจาก tray menu ด้วย |

### แท็บ Apache

| ค่า | ความหมาย / เมื่อไรควรแก้ |
|---|---|
| พอร์ต | ค่าเริ่ม 80 — เปลี่ยนเมื่อชนกับ XAMPP หรือต้องการหลายเซิร์ฟเวอร์ (8080 เป็นตัวยอดนิยม) |
| ServerName | ชื่อโดเมนของเซิร์ฟเวอร์ (ใช้ localhost เว้นแต่มี domain จริง) |
| ServerAdmin | อีเมลผู้ดูแล (แสดงในหน้า error) |
| DocumentRoot | โฟลเดอร์เว็บหลัก — ค่าเริ่ม `C:\zServer\www` เปลี่ยนได้ถ้าเก็บเว็บไว้ที่อื่น |
| KeepAlive | เปิดไว้เพื่อประสิทธิภาพปกติ |
| ThreadsPerChild | จำนวนเธรดพร้อมรับงาน (250 พอสำหรับเว็บทั่วไป) |
| โมดูลเสริม | rewrite (จำเป็นของ WordPress/Laravel), deflate (บีบอัด), expires (cache), directory listing |

### แท็บ PHP

| ค่า | ความหมาย / ค่าที่พบบ่อย |
|---|---|
| memory_limit | หน่วยความจำต่อ 1 สคริปต์ — 256M เหมาะทั่วไป, WordPress+plugin หนัก 512M |
| upload_max_filesize / post_max_size | ขนาดไฟล์อัพโหลดสูงสุด — อัพโหลดใหญ่ต้องเพิ่มสองค่านี้พร้อมกัน |
| max_execution_time | เวลารันสคริปต์สูงสุด (วินาที) — งาน import ใหญ่เพิ่มเป็น 300–600 |
| display_errors | เปิดเฉพาะตอนพัฒนา (ไม่ควรเปิดบนเซิร์ฟเวอร์จริง) |
| timezone | ค่าเริ่ม Asia/Bangkok |
| Extensions | เปิด/ปิดโมดูลเสริม (mysqli, mbstring, curl, gd, openssl, zip, intl, pdo_mysql ฯลฯ) |

### แท็บ MariaDB

| ค่า | ความหมาย / ค่าที่พบบ่อย |
|---|---|
| พอร์ต | ค่าเริ่ม 3306 — เปลี่ยนเป็น 3307 เมื่อใช้ร่วมกับ XAMPP |
| character-set / collation | ค่าเริ่ม utf8mb4 + utf8mb4_unicode_ci (รองรับไทยและ emoji) |
| innodb_buffer_pool_size | หน่วยความจำ cache ฐานข้อมูล — เครื่อง RAM 8GB ให้ 512M–1G ได้ |
| max_connections | จำนวนการเชื่อมต่อพร้อมกัน — 100 พอสำหรับเว็บทั่วไป |
| ตั้งรหัสผ่าน root | เปิดกล่องตั้งรหัสผ่าน (ต้องเริ่ม MariaDB ก่อน) — ค่าเริ่มต้นรหัสผ่านว่าง |

> โฟลเดอร์ข้อมูล (datadir) ปล่อยตามค่าเดิม — การย้าย datadir ต้องย้ายไฟล์ข้อมูลด้วยมือ

### แท็บเซอร์วิส

| ค่า | ความหมาย |
|---|---|
| โหมด Windows Service | ทำงานเบื้องหลัง เริ่มเองตอนเปิดเครื่อง (แนะนำ) |
| โหมด Process | แบบ XAMPP — เซอร์วิสรันเฉพาะตอนโปรแกรมเปิดอยู่ เหมาะกับทดลองชั่วคราว |
| ชื่อเซอร์วิส | ค่าเริ่ม `ZServerApache` / `ZServerMariaDB` — เปลี่ยนได้ถ้าชนกับเซอร์วิสเดิม |
| เริ่มอัตโนมัติ | auto = เริ่มเองตอนเปิดเครื่อง / demand = เริ่มเองเมื่อกดสั่ง |
| ปุ่มติดตั้ง/ถอนเซอร์วิส | จัดการเซอร์วิสโดยตรง (Apache จะทดสอบ config ก่อนติดตั้งให้ด้วย) |

## 5. หน้า "แก้ไขไฟล์ Config"

สำหรับผู้ใช้ขั้นสูงที่ต้องการแก้ directive ที่ไม่มีในฟอร์ม:

- เลือกไฟล์ได้ 4 ตัว: `httpd.conf`, `php.ini`, `my.ini`, `zserver.json`
- กด **บันทึก** — สำรองไฟล์เดิมลง `backups\configs\` ก่อนเสมอ
- ไฟล์ httpd.conf หลังบันทึกจะถูกทดสอบด้วย `httpd -t` ทันทีและรายงานผลให้
- ไฟล์ zserver.json จะตรวจว่า JSON ถูกรูปแบบก่อนเขียน

ข้อควรระวัง:
- ส่วนที่โปรแกรมจัดการ (ตัวอย่างเช่น Listen, DocumentRoot, ส่วน "zServer managed settings" ท้าย php.ini) จะ **ถูกเขียนทับ** เมื่อกดบันทึกในหน้า "ตั้งค่า" — ค่าที่แก้เองควรวางในจุดที่โปรแกรมไม่แตะ
- httpd.conf มีจุดต่อขยาย: สร้างไฟล์ `apache\conf\zserver-ชื่ออะไรก็ได้.conf` แล้ว Apache จะ include ให้อัตโนมัติ (เช่น ตั้ง vhost เอง) — ไฟล์นี้โปรแกรมไม่แตะต้อง

## 6. หน้า "ดู Logs"

ไฟล์ log ทั้งหมดรวมอยู่ที่ `logs\`:

| ชื่อ | ไฟล์ของใคร | ใช้ทำอะไร |
|---|---|---|
| Apache — error.log | `apache-error.log` | หาสาเหตุ Apache เปิดไม่ได้ / 500 error |
| Apache — access.log | `apache-access.log` | ดูว่าใครเข้าเว็บ คำขออะไร สถานะโค้ดอะไร |
| PHP — error log | `php-error.log` | error จากสคริปต์ PHP (เมื่อเปิด log_errors) |
| MariaDB — error log | `mariadb-error.log` | หาสาเหตุ MariaDB เปิดไม่ได้ |
| zServer Manager | `zserver-manager.log` | บันทึกการทำงานของโปรแกรมนี้เอง |

ปุ่ม: **รีเฟรช** / **รีเฟรชอัตโนมัติทุก 3 วิ** / **เปิดโฟลเดอร์ logs** / **ล้างไฟล์นี้** (แสดงท้ายไฟล์ 500 บรรทัดล่าสุด)

## 7. Workflow ที่ใช้บ่อย

### เปลี่ยนพอร์ต Apache เป็น 8080
ตั้งค่า → Apache → พอร์ต = 8080 → บันทึก → รีสตาร์ท Apache (ถ้าถาม) → เว็บอยู่ที่ http://localhost:8080

### เพิ่มขีดจำกัดอัพโหลดเป็น 256MB
ตั้งค่า → PHP → upload_max_filesize = 256M และ post_max_size = 256M → บันทึก → รีสตาร์ท Apache

### เปลี่ยนเวอร์ชัน PHP
ติดตั้ง/จัดการคอมโพเนนต์ → PHP เลือกเวอร์ชันใหม่ → ดาวน์โหลด + ติดตั้ง (โปรแกรมเขียน httpd.conf/php.ini ให้ใหม่เอง) → รีสตาร์ท Apache → ตรวจที่ /phpinfo.php

### เว็บที่ทำไว้ให้เพื่อนใน LAN เปิดได้
เปิดพอร์ต Firewall → ตรวจ IP เครื่อง (`ipconfig`) → เพื่อนเข้า http://<ip-เครื่องคุณ>

### สำรองฐานข้อมูลก่อนแก้พวงใหญ่
```
C:\zServer\mariadb\bin\mariadb-dump.exe --port=3306 -u root -p --all-databases > backup.sql
```

### เริ่มโปรเจกต์ PHP ใหม่
สร้างโฟลเดอร์ `www\myproject\` → เข้า http://localhost/myproject (หรือแก้ DocumentRoot ในหน้าตั้งค่าถ้าต้องการให้เป็นเว็บหลัก)
