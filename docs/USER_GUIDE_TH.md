### สัญลักษณ์สถานะ (อัพเดตทุก 3 วินาที)

| สัญลักษณ์ | ความหมาย |
|---|---|
| ● (เขียว) | กำลังทำงานปกติ |
| ○ (เทา) | หยุดอยู่ |
| ◌ (น้ำตาล) | ยังไม่ได้ติดตั้ง |
| ⚠ (ส้ม) | พอร์ตถูกโปรแกรมอื่นใช้ (มีชื่อโปรแกรม + วิธีแก้ใต้สถานะ) |

### ป้ายแจ้งเตือน "มีเวอร์ชันใหม่ ★"

โปรแกรมตรวจเวอร์ชันใหม่จากเว็บทางการตอนเปิด + ทุก 6 ชม. — เจอเวอร์ชันใหม่กว่าที่ติดตั้งจะ:
1. ขึ้น**ป้ายสีส้ม** บอกชัดว่าคอมโพเนนต์ไหน เวอร์ชันอะไร
2. เด้ง balloon จาก tray (กดได้ → เปิดหน้าอัพเดททันที)

### ปุ่มลัดหน้าจอ

- **− (ย่อ)** → ซ่อนไป tray (โปรแกรม+เซอร์วิสทำงานต่อ)
- **ปิดหน้าต่าง** ขณะเซอร์วิสรัน → ถาม: "หยุดเซอร์วิสก่อนปิด?" (ใช่/ไม่ใช่/ยกเลิก)

## 2. หน้า "ติดตั้ง / จัดการคอมโพเนนต์"

ใช้เมื่อ: ติดตั้งครั้งแรก / เปลี่ยนเวอร์ชัน / ติดตั้งซ้ำเพื่อซ่อมไฟล์

### แถวบนสุด — VC++ Redistributable

Apache/PHP ต้องมีตัวนี้ — โปรแกรมตรวจจากไฟล์ runtime จริงใน System32:
- ✓ เขียว = มีอยู่แล้ว (ข้ามได้)
- ⚠ ส้ม = กด **ดาวน์โหลดและติดตั้ง VC++ Redistributable** (โปรแกรมโหลดจาก aka.ms แล้วเรียกตัวติดตั้งของ Microsoft ให้) — หลังติดตั้งรีสตาร์ทเครื่องหนึ่งครั้ง

### แต่ละคอมโพเนนต์ (Apache / PHP / MariaDB)

1. ดูสถานะติดตั้งปัจจุบัน (เวอร์ชันที่ติดตั้งมีเครื่องหมาย ✓ ใน dropdown)
2. **dropdown เวอร์ชัน**: ดึงรายการใหม่จากเว็บทางการอัตโนมัติทุกครั้งที่เปิดหน้านี้ — เวอร์ชันใหม่ที่ออกทีหลังจะปรากฏเอง
3. กด **ดาวน์โหลด + ติดตั้ง** — โปรแกรมจะ:
   - ดาวน์โหลดพร้อม progress bar + ตรวจ SHA256 (PHP ได้ hash จาก php.net โดยตรง)
   - ถ้าพอร์ตชน → ถาม 3 ทางเลือก: "ใช่" ติดตั้งต่อ / **"ไม่ใช่" เปลี่ยนพอร์ตว่างอัตโนมัติแล้วติดตั้ง** / "ยกเลิก"
   - หยุดเซอร์วิสเดิม → **สำรองโฟลเดอร์เก่าลง backups\** → แตกไฟล์ → เขียน config → ทดสอบ
   - Apache: `httpd -t` ทดสอบ config ก่อนติดตั้ง service เสมอ
   - MariaDB: สร้าง datadir ครั้งแรก (ข้อมูลเดิมใน data\ ไม่ถูกแตะ)
4. **ติดตั้ง MariaDB เสร็จ** → โปรแกรมตรวจรหัสผ่าน root — ถ้ายังว่างจะ**ถามตั้งรหัสผ่านทันที** (เข้ารหัสเก็บ DPAPI เพื่อให้งานสำรองอัตโนมัติใช้)

### แถว Adminer (ไฟล์เดียว จัดการฐานข้อมูลผ่านเว็บ)

กด **ดาวน์โหลด + ติดตั้ง** → ไฟล์เดียวลง `www\adminer.php` (สำรองตัวเก่าเป็น .bak) → เปิด http://localhost/adminer.php ใช้ได้เลย

### ตัวเลือก "ติดตั้งเป็น Windows Service"

เปิดไว้ = ลงทะเบียนเซอร์วิส เริ่มเองตอนเปิดเครื่อง (ปิดได้ภายหลังที่แท็บ เซอร์วิส)

## 3. หน้า "อัพเดท"

ใช้เมื่อ: ต้องการเวอร์ชันใหม่ของคอมโพเนนต์ที่ติดตั้งอยู่

1. แถวบนแสดงเวอร์ชันที่ติดตั้งอยู่ตอนนี้ทั้ง 3 ตัว
2. กด **"ตรวจสอบเวอร์ชันล่าสุดจากเว็บทางการ"** — โปรแกรมสอบจาก:
   - PHP: `releases.json` ของ windows.php.net
   - Apache: หน้า download ของ ApacheLounge
   - MariaDB: หน้า archive ของ mariadb.org
3. แสดงผล: เวอร์ชันล่าสุดจากเว็บ / มีเวอร์ชันใหม่กว่าที่ติดตั้ง / หรือตรวจไม่สำเร็จ (ออฟไลน์)
4. กดปุ่ม **อัพเดท Apache / PHP / MariaDB** ของตัวที่ต้องการ — โปรแกรมจะเลือกเวอร์ชันจากผลตรวจให้ (หรือตัวล่าสุดในแคตตาล็อก) แล้วรันขั้นตอนเดียวกับหน้าติดตั้ง

### การอัพเดทที่ปลอดภัย

- หยุดเซอร์วิส → **สำรองโฟลเดอร์เดิมลง `backups\`** → ติดตั้งใหม่ → คง config เดิม
- **ข้อมูลฐานข้อมูลใน `data\` ไม่ถูกลบ**
- MariaDB ข้ามสายใหญ่ (เช่น 11.4 → 11.8): หลังอัพเดท+เริ่มเซอร์วิส รัน `mariadb\bin\mariadb-upgrade.exe --port=3306 -u root` หนึ่งครั้ง

### Rollback (กลับเวอร์ชันเก่า)

1. หยุดเซอร์วิสที่เกี่ยวข้อง
2. ลบโฟลเดอร์ใหม่ (`apache\` / `php\` / `mariadb\`)
3. ย้ายโฟลเดอร์จาก `backups\<ชื่อ>-old-<วันเวลา>\` กลับมาใช้ชื่อเดิม
4. เริ่มเซอร์วิส

## 4. หน้า "ตั้งค่า" — 6 แท็บ

ทุกครั้งที่กด **บันทึกและใช้ค่าใหม่**: บันทึก `zserver.json` → จัดการ autostart → เขียน config ที่เกี่ยวข้องใหม่ (สำรองเดิมก่อนเสมอ) → ถามรีสตาร์ทเซอร์วิสถ้ากำลังรัน

### แท็บ ทั่วไป

| ค่า | ความหมาย |
|---|---|
| ☑ เปิดโปรแกรมอัตโนมัติเมื่อเข้าสู่ระบบ Windows | สร้าง Task Scheduler `ZServerManager` (Run with highest privileges) — เปิดเองตอน logon พร้อมสิทธิ์ admin ไม่เด้ง UAC |
| ☑ เริ่มเซอร์วิส Apache + MariaDB ทันทีที่เปิดโปรแกรม | ใช้คู่กัน → เว็บพร้อมใช้หลัง logon |
| ☑ ย่อ/ปิดหน้าต่างแล้วซ่อนไว้ใน tray | เปิดมาเงียบ ๆ |
| ☑ ใช้ธีมมืด | ธีมมืด/สว่าง (หน้าหลักปรับทันที — สลับเร็วจาก tray menu ด้วย) |
| ☑ Watchdog เซอร์วิส | ตรวจทุก 30 วิ — เจอเซอร์วิสหยุดเอง → แจ้งเตือน tray + เริ่มให้ใหม่อัตโนมัติ (ไม่นับตอนผู้ใช้กดหยุดเอง) |
| เก็บไฟล์ log ไว้กี่วัน (0 = ไม่จำกัด) | log เก่าถูกบีบอัดเก็บ `backups\log-archives\` ตอนเปิดโปรแกรม |

### แท็บ Apache

| ค่า | ความหมาย / เมื่อไรควรแก้ |
|---|---|
| พอร์ต (HTTP) | ค่าเริ่ม 80 — เปลี่ยนเมื่อชนกับ XAMPP (8080 ยอดนิยม) |
| ServerName / ServerAdmin | ชื่อโดเมน + อีเมลผู้ดูแล |
| DocumentRoot | โฟลเดอร์เว็บหลัก (ค่าเริ่ม `C:\zServer\www`) |
| KeepAlive / ThreadsPerChild | ประสิทธิภาพ — ค่าเริ่มเหมาะทั่วไป |
| โมดูลเสริม | rewrite (WordPress/Laravel), deflate (บีบอัด), expires (cache), directory listing |
| HTTPS | ปุ่ม "จัดการ HTTPS…" — เปิดหน้าจัดการครบวงจร (ดู §7) |

### แท็บ PHP

| ค่า | ความหมาย |
|---|---|
| **เวอร์ชัน PHP ที่ใช้งาน** | dropdown แสดงทุกเวอร์ชันใน `php-versions\` + ปุ่ม **สลับเวอร์ชัน** — โปรแกรมหยุด Apache → เปลี่ยน junction → เขียน php.ini → เริ่ม Apache ให้ (3 วินาทีจบ) |
| memory_limit | หน่วยความจำต่อสคริปต์ (256M ทั่วไป, WordPress หนัก 512M) |
| upload_max_filesize / post_max_size | อัพโหลดใหญ่สุด — เพิ่มสองค่าพร้อมกัน |
| max_execution_time | เวลารันสคริปต์ (import ใหญ่ 300–600) |
| display_errors / log_errors | เปิด display เฉพาะตอนพัฒนา |
| OPcache | เว็บไวขึ้น (เปิดไว้) |
| **Xdebug (VS Code)** | เปิด debug + พอร์ต 9003 — แถว "สถานะ Xdebug" บอกว่ามี `php_xdebug.dll` หรือยัง (ไม่มี → โหลดจาก xdebug.org/wizard วางที่ `php\ext\`) |
| เขตเวลา | ค่าเริ่ม Asia/Bangkok |
| Extensions (โมดูลเสริม) | จัดกลุ่มตามหมวด (ฐานข้อมูล/ข้อความ/เว็บ) พร้อมคำอธิบายไทย — **ตัวที่ไม่มีไฟล์ในรุ่น PHP ที่ใช้ จะเทาพร้อมหมายเหตุ** |

### แท็บ MariaDB

| ค่า | ความหมาย |
|---|---|
| พอร์ต | ค่าเริ่ม 3306 |
| การเข้าถึง | ☑ อนุญาตเฉพาะเครื่องนี้ (127.0.0.1 — ค่าเริ่มต้น ปลอดภัย) — ปิด = เครื่องอื่นเข้าได้ (มีเตือน) |
| สำรองข้อมูลอัตโนมัติ | ☑ เปิด + เวลา (HH:mm) + เก็บกี่วัน — รัน `mariadb-dump --all-databases` ทุกวัน → `backups\databases\` |
| ทำสำรองเดี๋ยวนี้ / เปิดโฟลเดอร์ | ปุ่มสำรองด่วน (แสดงสำรองล่าสุด + จำนวนไฟล์) |
| รหัสผ่าน root (งานอัตโนมัติ) | เข้ารหัส DPAPI เก็บในเครื่อง — ให้ backup อัตโนมัติยืนยันตัวเองได้ |
| character-set / collation | utf8mb4 (รองรับไทย+emoji) |
| innodb_buffer_pool_size | RAM cache ฐานข้อมูล (เครื่อง 8GB ให้ 512M–1G) |
| ตั้งรหัสผ่าน root… | กล่องตั้งรหัสผ่าน (ต้องเริ่ม MariaDB ก่อน) — หลังตั้งโปรแกรมเก็บเข้ารหัสให้เอง |

### แท็บ Virtual Hosts

สร้างเว็บหลายเว็บในเครื่องเดียว:

1. ใส่**ชื่อโดเมน** เช่น `myproject.local`
2. เลือก**โฟลเดอร์เว็บ** (ถ้าว่าง โปรแกรมสร้าง `www\<ชื่อ>\` ให้)
3. กด **เพิ่มเว็บ** → ปรากฏในรายการ (เครื่องหมายถูก = เปิดใช้)
4. กด **บันทึกและใช้ค่าใหม่** — โปรแกรมจะ:
   - สร้าง `conf\zserver-vhosts.conf` (vhost ทุกตัว)
   - **แก้ hosts file** เพิ่ม `127.0.0.1 myproject.local` (สำรอง hosts เดิมก่อน — แก้เฉพาะ section ของ zServer)
   - ถามรีสตาร์ท Apache
5. เข้าเว็บได้ที่ `http://myproject.local`

ลบเว็บ: เลือกในรายการ → กด "ลบที่เลือก" → บันทึก

### แท็บ เซอร์วิส

| ค่า | ความหมาย |
|---|---|
| โหมด Windows Service / Process | Service = เบื้องหลัง เริ่มเองตอนเปิดเครื่อง / Process = แบบ XAMPP (หยุดเมื่อปิดโปรแกรม) |
| ชื่อเซอร์วิส | ค่าเริ่ม `ZServerApache` / `ZServerMariaDB` |
| เริ่มอัตโนมัติ | auto / demand |
| ปุ่มติดตั้ง/ถอนเซอร์วิส | จัดการโดยตรง (Apache จะทดสอบ config ก่อนติดตั้งให้) |

## 5. หน้า "ฐานข้อมูล"

สร้าง database + user พร้อม connection string ในคลิกเดียว:

1. (ถ้า root มีรหัสผ่าน) ใส่รหัสผ่าน root ในกล่องแรก — เว้นว่างถ้าไม่เคยตั้ง (โปรแกรมใช้ค่าที่เข้ารหัสเก็บไว้อัตโนมัติถ้ามี)
2. ใส่**ชื่อ database** (a-z 0-9 _) — ชื่อ user จะตามอัตโนมัติ (แก้ได้)
3. ใส่**รหัสผ่าน user** (กด "สุ่มรหัสผ่าน" ได้) + ยืนยัน
4. กด **สร้าง Database + User** — โปรแกรมจะ:
   - `CREATE DATABASE ... utf8mb4`
   - `CREATE USER ... 'localhost'` + `'127.0.0.1'` (รองรับ TCP)
   - `GRANT ALL PRIVILEGES`
5. **connection string โผล่พร้อมคัดลอก**:
   ```
   // mysqli
   $conn = mysqli_connect("127.0.0.1", "user", "pass", "db", 3306);
   // PDO
   $pdo = new PDO("mysql:host=127.0.0.1;port=3306;dbname=db", "user", "pass");
   ```
6. ฝั่งขวาแสดง**รายชื่อฐานข้อมูลที่มีอยู่** (กดรีเฟรชได้)

## 6. หน้า "เว็บใหม่"

สร้างเว็บใหม่จากเทมเพลต ครบทั้งโฟลเดอร์ + DB + โดเมน:

1. ใส่**ชื่อเว็บ** เช่น `myshop` → โฟลเดอร์ `www\myshop\` + โดเมน `myshop.local` + DB `myshop`
2. เลือกเทมเพลต:
   - **เว็บเปล่า** — ได้ index.php พร้อมเขียนต่อ
   - **WordPress** — ดาวน์โหลดจาก wordpress.org (~25MB) แตกลงเว็บให้
3. ☑ สร้าง database + user (ชื่อตามเว็บ)
4. ☑ สร้าง Virtual Host (`myshop.local` — แก้ hosts file ให้เอง)
5. ใส่รหัสผ่าน root ของ MariaDB (ถ้ามี) → กด **สร้างเว็บใหม่**
6. ผลลัพธ์แสดง: URL + **ข้อมูล DB สำหรับ setup WordPress** (DB/User/Pass/Host/Port)
7. ปุ่ม **เปิดเว็บ** / **เปิดโฟลเดอร์เว็บ**

> WordPress: เปิด URL แล้วทำตามตัวติดตั้งใน browser โดยกรอกข้อมูล DB ตามที่โปรแกรมแสดง

## 7. หน้า "จัดการ HTTPS"

ศูนย์กลางจัดการ HTTPS 3 ขั้นตอน พร้อม**สถานะจริงของใบรับรอง** (อ่านจาก openssl — subject, วันหมดอายุ, โดเมนที่ครอบคลุม):

### ขั้น ① สร้าง / ต่ออายุใบรับรอง (mkcert — สำหรับพัฒนางาน)

- กดปุ่มเดียว: โปรแกรมโหลด mkcert จาก GitHub (ครั้งแรก) → สร้าง CA → ติดตั้งเข้า Windows trust store ผ่าน certutil → ออกใบรับรอง **ครอบคลุม localhost + Virtual Host ทุกตัว**
- browser (Chrome/Edge) เปิด https://localhost ได้**โดยไม่มีคำเตือน**
- เพิ่มเว็บใหม่ภายหลัง → กดปุ่มนี้ซ้ำ ใบรับรองจะครอบคลุมโดเมนใหม่ให้เอง

### ขั้น ② เปิด/ปิด HTTPS

- ☑ เปิด HTTPS + พอร์ต (443) → กด **บันทึกและเปิด HTTPS** → โปรแกรมเขียน config (เว็บหลัก + vhost ทุกตัวมี https) → ถามรีสตาร์ท Apache

### ขั้น ③ ใช้งานจริง

- **รีสตาร์ท Apache เดี๋ยวนี้** / **เปิดพอร์ต 443 ใน Firewall** / **ทดสอบเปิด https://localhost**

### นำเข้าใบรับรองจริงที่ซื้อมา

กดปุ่ม **"นำเข้าใบรับรองจริงที่ซื้อมา (.crt/.key/.pfx)"** — ดูรายละเอียดเต็มที่ §8

> ข้อจำกัด: ใบรับรอง mkcert ใช้ได้บนเครื่องที่ติดตั้ง CA ไว้เท่านั้น (เหมาะพัฒนางาน) — เว็บจริงบน server ใช้ Let's Encrypt หรือใบรับรองที่ซื้อมา (นำเข้าได้ผ่านหน้านี้)

## 8. หน้า "นำเข้าใบรับรองจริง"

สำหรับใบรับรองที่ซื้อมาจริง (Sectigo/DigiCert ฯลฯ) — โปรแกรมจัดการทุกขั้นที่ยุ่งยากให้:

| ช่อง | ใส่อะไร |
|---|---|
| **① ไฟล์ใบรับรอง** | `.crt` / `.pem` / `.cer` — หรือ **`.pfx/.p12` ไฟล์เดียวจบ** (ช่อง ② จะเคลียร์ให้เอง) |
| **② ไฟล์ private key** | `.key` / `.pem` ที่คู่กับ cert (ถ้าใช้ pfx เว้นว่าง) |
| **③ CA bundle** (ถ้ามี) | ไฟล์ ca-bundle/intermediate จากผู้ขาย — ทำให้ chain ครบ browser ไม่เตือน |
| รหัสผ่าน key/pfx | ถ้าไฟล์เข้ารหัสไว้ |

กด **"นำเข้าและตรวจสอบ"** แล้วโปรแกรมจะ:
1. แปลงเป็น PEM ให้เอง (รองรับ DER ด้วย)
2. แปลง private key (RSA/EC/encrypted — ใส่รหัสผ่านได้)
3. **ตรวจว่า key ตรงกับ cert** (เทียบ public key — key ผิดจะบอกทันที)
4. ต่อ CA chain ให้ cert ครบ
5. แสดงข้อมูลใบรับรอง (subject / หมดอายุ / โดเมน)
6. ถาม **"เปิด HTTPS และรีสตาร์ท Apache เดี๋ยวนี้ไหม?"** → กด Yes จบ

⚠ ไม่ใส่ CA bundle → บาง browser/มือถืออาจเตือน chain ไม่ครบ (ขอไฟล์ ca-bundle จากผู้ขายแล้วนำเข้าซ้ำได้)

## 9. หน้า "แก้ไขไฟล์ Config"

สำหรับผู้ใช้ขั้นสูง:

- เลือกไฟล์ได้ 4 ตัว: `httpd.conf`, `php.ini`, `my.ini`, `zserver.json`
- **กดที่ช่องเลือกไฟล์ หรือปุ่ม "เลือกไฟล์…"** เพื่อเปิดหน้าเลือกไฟล์ทันที
- กด **บันทึก** — สำรองไฟล์เดิมลง `backups\configs\` ก่อนเสมอ
- บันทึก httpd.conf → ทดสอบ `httpd -t` ให้ทันที + รายงานผล
- บันทึก zserver.json → ตรวจ JSON ก่อนเขียน

ข้อควรระวัง:
- ส่วนที่โปรแกรมจัดการ (Listen, DocumentRoot, managed block ท้าย php.ini) จะ**ถูกเขียนทับ**เมื่อกดบันทึกในหน้า "ตั้งค่า"
- จุดต่อขยายที่โปรแกรมไม่แตะ: `apache\conf\zserver-*.conf` (เช่น ตั้ง vhost เอง) และส่วนนอก managed block ของ php.ini

## 10. หน้า "ดู Logs" + สรุปสถิติ

ไฟล์ log ทั้งหมดรวมอยู่ที่ `logs\`:

| ชื่อ | ไฟล์ | ใช้ทำอะไร |
|---|---|---|
| Apache — error.log | `apache-error.log` | หาสาเหตุ Apache เปิดไม่ได้ / 500 error |
| Apache — access.log | `apache-access.log` | ดูว่าใครเข้าเว็บ คำขออะไร |
| PHP — error log | `php-error.log` | error จากสคริปต์ PHP |
| MariaDB — error log | `mariadb-error.log` | หาสาเหตุ MariaDB เปิดไม่ได้ |
| zServer Manager | `zserver-manager.log` | บันทึกการทำงานของโปรแกรมเอง |

ปุ่ม: **รีเฟรช** / รีเฟรชอัตโนมัติ 3 วิ / **สรุปสถิติ access.log** / **เปิดโฟลเดอร์ logs** / **ล้างไฟล์นี้** (แสดงท้ายไฟล์ 500 บรรทัด)

### หน้า "สรุปสถิติ access.log"

กดปุ่ม "สรุปสถิติ access.log" → วิเซต combined log format แสดง 3 ตาราง:

- **Top IP (ผู้เข้าชม)** — 10 อันดับ
- **Top หน้าเว็บ (path)** — 10 อันดับ
- **สถานะ HTTP** — 200/404/500 มีกี่ครั้ง

ไฟล์ใหญ่มากจะวิเซต 300,000 บรรทัดล่าสุดพอ

## 11. Tray icon

ปุ่มย่อหน้าต่าง (−) → ซ่อนไป tray (โปรแกรม+เซอร์วิสทำงานต่อ) เมนูคลิกขวาที่ไอคอน tray:

| เมนู | หน้าที่ |
|---|---|
| แสดงหน้าต่างหลัก | เปิดกลับ |
| เริ่มทั้งหมด / หยุดทั้งหมด | ควบคุมเซอร์วิสด่วน |
| เปิดเว็บ localhost | เปิด browser |
| **สลับธีมมืด/สว่าง** | เปลี่ยนธีมทั้งโปรแกรม |
| ออกจากโปรแกรม | ปิด (ถามหยุดเซอร์วิสไหมถ้ากำลังรัน) |

แจ้งเตือนจาก tray: เวอร์ชันใหม่ / เซอร์วิสล้ม (watchdog) — กด balloon เปิดหน้าที่เกี่ยวข้องทันที

## 12. Workflow ที่ใช้บ่อย

### เปลี่ยนพอร์ต Apache เป็น 8080
ตั้งค่า → Apache → พอร์ต = 8080 → บันทึก → รีสตาร์ท Apache → เว็บอยู่ที่ http://localhost:8080

### เพิ่มขีดจำกัดอัพโหลดเป็น 256MB
ตั้งค่า → PHP → upload_max_filesize = 256M + post_max_size = 256M → บันทึก → รีสตาร์ท Apache

### สลับเวอร์ชัน PHP (เร็ว)
ตั้งค่า → PHP → "เวอร์ชัน PHP ที่ใช้งาน" เลือกเวอร์ชัน → สลับเวอร์ชัน → ตรวจที่ /phpinfo.php

### สร้างเว็บ WordPress ใหม่ครบชุด
เว็บใหม่ → ชื่อ `myshop` → เลือก WordPress → ☑ DB ☑ vhost → ใส่รหัส root → สร้าง → เปิด URL ทำตามตัวติดตั้ง WordPress (ใช้ DB ตามที่โปรแกรมแสดง)

### สร้าง DB + user สำหรับโปรเจกต์ที่มีอยู่
ฐานข้อมูล → ชื่อ DB/user/รหัสผ่าน → สร้าง → คัดลอก connection string → วางในโค้ด

### เว็บที่ทำไว้ให้เพื่อนใน LAN เปิดได้
เปิดพอร์ต Firewall → ตรวจ IP (`ipconfig`) → เพื่อนเข้า http://<ip-เครื่องคุณ>

### สำรองฐานข้อมูลก่อนแก้พวงใหญ่
MariaDB tab → กด "สำรองเดี๋ยวนี้" หรือเปิดสำรองอัตโนมัติทุกวัน

### เปิด HTTPS สำหรับ dev
HTTPS → ① สร้างใบรับรอง → ② บันทึกและเปิด → ③ รีสตาร์ท → https://localhost (browser เชื่อ)

### นำเข้าใบรับรองจริงที่ซื้อมา
HTTPS → "นำเข้าใบรับรองจริง…" → เลือกไฟล์ .crt + .key (+ CA bundle) → นำเข้า → เปิด HTTPS → รีสตาร์ท

### สำรองฐานข้อมูลก่อนแก้พวงใหญ่ (มือ)
```
C:\zServer\mariadb\bin\mariadb-dump.exe --port=3306 -u root -p --all-databases > backup.sql
```

### เริ่มโปรเจกต์ PHP ใหม่
สร้างโฟลเดอร์ `www\myproject\` → เข้า http://localhost/myproject (หรือใช้ Virtual Hosts ให้มีโดเมนเอง)
