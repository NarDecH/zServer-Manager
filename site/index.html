12 ความสามารถหลัก ในไฟล์เดียว

ทุกอย่างที่ต้องใช้พัฒนาเว็บบนเครื่อง Windows — ไม่ต้องเปิดหลายโปรแกรม ไม่ต้องจำคำสั่ง ภาษาไทยทั้งหมด

ติดตั้งคลิกเดียว

ดาวน์โหลด Apache / PHP / MariaDB จากเว็บทางการ ตรวจ SHA256 แตกไฟล์ เขียน config เชื่อมกันเอง ติดตั้งเป็น Windows Service — บวก Adminer จัดการฐานข้อมูลผ่านเว็บ

สลับ PHP หลายเวอร์ชัน

เก็บได้หลายเวอร์ชัน (8.5 / 8.6 …) สลับใน 3 วินาทีผ่านระบบ junction — ไม่ต้องโหลดซ้ำ ไม่ต้องแก้ config

แจ้งเตือน + อัพเดทอัตโนมัติ

ตรวจเวอร์ชันใหม่จากเว็บทางการทุก 6 ชม. เจอของใหม่เด้งแจ้งเตือน tray — กดอัพเดทได้เลย สำรองก่อนเสมอ rollback ได้

ฐานข้อมูลในคลิกเดียว

สร้าง database + user + grant พร้อม connection string คัดลอกไปวางในโค้ดได้ทันที — บวกสำรองข้อมูลอัตโนมัติทุกวัน

Virtual Hosts หลายเว็บ

เพิ่ม myproject.local ในไม่กี่คลิก — โปรแกรมสร้าง vhost config + แก้ hosts file ให้เอง (สำรองเดิมก่อนทุกครั้ง)

HTTPS ง่ายสุด ๆ

ใบรับรอง dev ด้วย mkcert (browser เชื่อไม่เตือน) หรือนำเข้าใบรับรองจริงที่ซื้อมา .crt/.key/.pfx — ตรวจ key ตรง cert ให้อัตโนมัติ ครอบคลุมทุกเว็บ

สร้างเว็บจากเทมเพลต

เว็บเปล่า หรือ WordPress ดาวน์โหลดให้พร้อม database + user + โดเมน — จบใน 2 นาที ไม่ต้องเปิด phpMyAdmin

Watchdog เซอร์วิสล้ม

ตรวจทุก 30 วินาที — เซอร์วิสตายเองเด้งแจ้งทันที เปิดโหมดเริ่มให้ใหม่อัตโนมัติได้ (ไม่นับตอนผู้ใช้กดหยุดเอง)

ตั้งค่าครบ ภาษาไทย

พอร์ต, DocumentRoot, memory_limit, extensions (พร้อมคำอธิบาย), Xdebug, MariaDB, autostart — บันทึกทีเดียวสำรองไฟล์เดิมให้ก่อนเสมอ

Log + สถิติ + Rotation

ดู log ทุกตัวในโปรแกรม สรุปสถิติ access.log (Top IP/หน้าเว็บ/status) log เก่าบีบอัดเก็บอัตโนมัติ ตั้งเก็บไว้กี่วันได้

Terminal พร้อม PATH

เปิด cmd ที่โฟลเดอร์เว็บ มี php + mariadb ใน PATH ทันที — รัน migration, composer, dump ได้เลย

ธีมมืด/สว่าง + autostart

สลับธีมจาก tray, เปิดโปรแกรมเองตอน logon พร้อมสิทธิ์ admin ไม่เด้ง UAC, ย่อไป tray ได้

คอมโพเนนต์

ของจริงจากเว็บทางการ เวอร์ชันล่าสุดอัตโนมัติ

รายการเวอร์ชันดึงสดจาก php.net / ApacheLounge / MariaDB archive ทุกครั้งที่เปิดหน้าติดตั้ง — เวอร์ชันใหม่ที่ออกทีหลังโปรแกรมจะรู้เอง

ถาม-ตอบ

คำถามที่พบบ่อย

ใช้คู่กับ XAMPP ที่ติดตั้งไว้แล้วได้ไหม?

ได้ และไม่กระทบกันเลย — ถ้า XAMPP กำลังรันอยู่ โปรแกรมจะตรวจพอร์ตชนและแจ้งว่าใครใช้ พร้อมปุ่มเปลี่ยนพอร์ตเป็น 8080/3307 อัตโนมัติ หรือจะหยุด XAMPP แล้วใช้พอร์ต 80/3306 กับ zServer ก็ได้

สลับเวอร์ชัน PHP ยังไง?

ติดตั้งเวอร์ชันที่ต้องการผ่านหน้า "ติดตั้ง" ครั้งเดียว — โปรแกรมเก็บไว้ที่ php-versions\ จากนั้นไปที่ ตั้งค่า → PHP → เลือกเวอร์ชัน → กดสลับ (Apache หยุด-เริ่มให้อัตโนมัติ ใช้เวลาไม่กี่วินาที) — กลับมาเวอร์ชันเดิมเมื่อไรก็ได้

HTTPS ใช้ใบรับรองจากไหน?

สำหรับพัฒนางาน: โปรแกรมใช้ mkcert สร้างใบรับรอง + ติดตั้ง CA เข้า Windows — Chrome/Edge เชื่อทันทีไม่มีคำเตือน ครอบคลุม localhost และ Virtual Host ทุกตัว ส่วนเว็บจริงบน server สามารถนำเข้าใบรับรองจริงที่ซื้อมา (.crt/.key/.pfx) ผ่านปุ่มในหน้าเดียวกันได้

ทำไมต้องกด UAC ทุกครั้งตอนเปิดโปรแกรม?

โปรแกรมควบคุม Windows Service และ hosts file ซึ่งต้องการสิทธิ์ admin — ถ้าไม่อยากกดบ่อย ใช้ตัวเลือก "เปิดโปรแกรมอัตโนมัติเมื่อเข้าสู่ระบบ" ในหน้าตั้งค่า (Task Scheduler ให้สิทธิ์ admin โดยไม่เด้ง UAC ตอน logon)

ข้อมูลหายไหมตอนอัพเดท/ถอนติดตั้ง?

ไม่หาย — ทุกการอัพเดท/ติดตั้งทับจะสำรองโฟลเดอร์เดิมลง backups\ ก่อนเสมอ, ข้อมูลฐานข้อมูลอยู่ที่ data\ แยกจากโฟลเดอร์โปรแกรม, ถอน Setup.exe จะลบเฉพาะไฟล์โปรแกรม (ไม่ลบ www\, data\, เซอร์วิส)
